🏃‍♀️ UNESA Running Fest Website
Website resmi UNESA Running Fest 5K 2025 yang dibuat menggunakan HTML, CSS, dan JavaScript.
Project ini menampilkan informasi seputar:
- Program latihan lari (5K & 10K)
- Galeri event lari UNESA
- Detail event UNESA 5K RUN 2025
- Syarat & ketentuan pendaftaran
- Link Google Form pendaftaran
